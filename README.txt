# Birthday Website

A 10-page friendship/gratitude birthday website.

## Files
- index.html through page10.html: separate pages
- css/style.css: shared styling
- js/script.js: shared animations/interactions
- assets/images/: put photos here
- assets/music/: optional music can be added here later

## How to run
Open `index.html` in a browser.

## Notes
The wording is intentionally friendly and non-romantic. You can replace the text and photo placeholders with your own content.
